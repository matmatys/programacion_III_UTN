# class-16 backend/chat-core-service-end

Final backend for class 16.

Includes:
- JWT auth flow,
- Bearer-protected chat endpoints,
- SQLite persistence through TypeORM,
- conversation and message repositories.

## Run

```bash
npm install
npm run start:dev
```

- API base: `http://localhost:5001`
- Swagger: `http://localhost:5001/api`
