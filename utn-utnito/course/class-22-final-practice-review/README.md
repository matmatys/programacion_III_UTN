# Clase 22 - Repaso final de practica

## Espanol

### Objetivo
Cerrar el recorrido practico de UTNito repasando las clases 01 a 21 sin escribir codigo nuevo.

La clase busca que el alumno pueda:
- ordenar la evolucion desde HTML estatico hasta una aplicacion full stack con AI,
- reconocer que problema resolvio cada clase,
- conectar los conceptos minimos vistos en clase con una version final integrada,
- leer el `full_project` como referencia de arquitectura, sin asumir que ya lo vio completo.

### Duracion sugerida
60-75 minutos.

### Estructura de la clase
- `slides/outline.md`: slides conceptuales para repasar toda la practica.
- No hay steps.
- No hay workspace start/end.
- No hay comandos obligatorios.

### Flujo sugerido
1. Presentar el objetivo de cierre: entender el camino completo, no memorizar codigo.
2. Recorrer las clases en bloques:
   - web base,
   - Angular y frontend,
   - contrato API y backend,
   - robustez de aplicacion,
   - Docker, n8n y AI.
3. Usar el `full_project` solo como referencia final si aparece una duda concreta.
4. Cerrar con el mapa mental de UTNito completo.

### Checkpoint
El alumno puede explicar, en sus palabras, como evoluciono UTNito desde una pantalla estatica hasta un sistema con frontend, backend, persistencia, Docker, n8n y proveedores AI.

## English

### Goal
Close the UTNito practical path by reviewing classes 01 to 21 without writing new code.

Students should be able to:
- understand the evolution from static HTML to a full stack AI-enabled application,
- identify the problem solved in each class,
- connect the minimal class versions with a final integrated version,
- read the `full_project` as an architecture reference, even if they have not explored it before.

### Suggested duration
60-75 minutes.

### Class structure
- `slides/outline.md`: conceptual slides for the full practice review.
- No steps.
- No start/end workspace.
- No required commands.

### Checkpoint
Students can explain how UTNito evolved into a system with frontend, backend, persistence, Docker, n8n, and AI providers.
