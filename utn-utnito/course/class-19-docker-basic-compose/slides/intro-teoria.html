Clase 19 - Docker basico y docker-compose

Objetivo: empaquetar backend y frontend, y levantar el stack con Compose.

Idea central

Hasta ahora corriamos proyectos. Hoy empaquetamos un ambiente reproducible.

Estados del stack

  • Backend en contenedor: chat-core-service
  • Frontend en contenedor: chat-frontend
  • SQLite persistido en volumen Docker
  • Red interna: utn-utnito-network-class-19

Checkpoint

  • http://localhost:4300 abre el frontend.
  • http://localhost:4012/api abre Swagger.
  • docker compose ps muestra servicios healthy.
  • Docker Desktop permite revisar containers y logs.
