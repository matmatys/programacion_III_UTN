# Class 17 backend/chat-core-service-start

Baseline backend for class 17.

This start project comes from class 16 end and is used as the base for:
- environment config,
- global error filter,
- global validation pipe,
- final consistency cleanup.

## Run

```bash
npm install
npm run start:dev
```

- API base: `http://localhost:5001`
- Swagger: `http://localhost:5001/api`
