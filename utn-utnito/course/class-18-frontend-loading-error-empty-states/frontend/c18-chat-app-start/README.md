# c18-chat-app-start

Estado inicial del frontend para clase 18.

Igual al estado final del frontend de clase 16 (que a su vez era igual al estado final del frontend de clase 15). La lista de conversaciones del chat solo maneja el happy path: si carga, no se nota; si falla, queda en blanco; si esta vacia, no dice nada util.

A lo largo de los steps se le agrega manejo explicito de `loading`, `empty` y `error`.

Path: `course/class-18-frontend-loading-error-empty-states/frontend/c18-chat-app-start`

## Run

```bash
npm install
npm run start
```

Open: `http://localhost:5300`
